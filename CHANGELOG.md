# 📄 Changelog

Todas las modificaciones importantes en este proyecto se documentarán en este archivo.

Este proyecto sigue la [Semantic Versioning](https://semver.org/lang/es/) y la guía de [Keep a Changelog](https://keepachangelog.com/en/1.0.0/).

---

## [1.0.0] - 2025-03-13

### 🎉 Added
- Publicación inicial del curso **MAT281 - Matemáticas Aplicadas**.
- Documentación completa usando **MkDocs Material**.
- Configuración de control de calidad con `pre-commit`.
- Pruebas iniciales con `pytest` en la carpeta `tests/`.
- Integración de `pyproject.toml` para la gestión del entorno con `poetry`.
- Configuración de despliegue en **GitHub Pages** para la documentación.
- Integración con **Zenodo** para la gestión del DOI.

### 🔄 Changed
- Actualización en la estructura del directorio `.devcontainer`.
- Mejoras en el archivo `.pre-commit-config.yaml` para controlar calidad en los archivos Markdown y Python.
- Optimización de la estructura en la carpeta `docs/` para una navegación más clara.

### 🐛 Fixed
- Corrección de rutas en `mkdocs.yml` para la documentación.
- Ajustes menores en el formato de los archivos `README.md` y `CONTRIBUTING.md`.

### ❌ Removed
- Eliminados archivos redundantes de pruebas iniciales.
