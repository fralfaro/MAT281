## ¿Qué es GitHub?

GitHub es una plataforma web para alojar, versionar y compartir proyectos de forma colaborativa. Funciona como una "nube" para tus archivos de trabajo, con la ventaja de registrar cada cambio que hagas.

**¿Por qué usarlo en educación?**

- Organiza apuntes, tareas y proyectos en un solo lugar.
- Permite compartir materiales con un simple enlace.
- Deja registro de cada versión de tu trabajo
    - ¡adiós al `informe_v2_final_definitivo.docx`!.

## Crear una cuenta

1. Ve a [github.com](https://github.com) y haz clic en **Sign up**.

      ![Página principal de GitHub](https://fralfaro.github.io/talks/tools/github/images/github/acc_01.png)

2. Ingresa tu correo electrónico y haz clic en **Continue**.

      ![Formulario de registro — email](https://fralfaro.github.io/talks/tools/github/images/github/acc_02.png)

3. Crea una contraseña y elige un nombre de usuario.

      ![Formulario de registro — datos completos](https://fralfaro.github.io/talks/tools/github/images/github/acc_03.png)

4. Verifica tu cuenta con el código que recibirás por correo.

      ![Verificación de cuenta](https://fralfaro.github.io/talks/tools/github/images/github/acc_04.png)

5. ¡Listo! Ya estás dentro de tu cuenta.

    ![Dashboard de GitHub tras el registro](https://fralfaro.github.io/talks/tools/github/images/github/acc_05.png)

> 💡 **Consejos:** usa un nombre de usuario profesional (ej: `francisco-alfaro`), agrega foto de perfil y una bio breve. Con la cuenta gratuita tienes repositorios públicos y privados ilimitados.
